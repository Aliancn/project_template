## 归档

`archive/` 下为已完结/已弃用的历史记录，不再活跃使用。

- **事件批量归档**：同一事件的连续多篇过程记录，收敛为一篇统一记录后，旧文移入 `archive/<事件>_<MMDD>/`，并在本文件归档节说明新入口（优先读统一记录）。
- **勘误传播**：修正一条结论时，全库检索相关引用（INDEX / 相关 devlog / docs / README）逐处同步，不只在原地改。
