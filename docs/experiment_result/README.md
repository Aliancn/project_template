# 冻结实验结果（experiment_result/）

本目录收录**冻结的实验结论**：稳定、可长期引用的实验结果页（矩阵 / 关键数字 / 判定）。过程与原始分析留在 `devlog/`，本目录只收提炼后的结论并链接回证据。

## 收录契约

- **冻结才收**：实验已确认、结论不再变动（非进行中、非易变中间量）；进行中的过程记录一律留 `devlog/`。
- **来源可追溯**：每页标注来源 devlog 链接 + 代码版本（分支 / commit）+ 关键运行配置（显存档位、并行度、数据集、预算等），保证可复核。
- **同页维护**：重跑后更新同页数字与结论，不新建页；页脚 `Last updated: mm/dd/yyyy` 同步更新。
- **命名**：`{主题}.md`（snake_case 英文主题），与机制页互链（机制页 → 结果页；结果页 → 来源 devlog）。
- **索引**：新页在 [`../README.md`](../README.md) 的 `experiment_result/` 板块登记一行（一句话摘要）。
