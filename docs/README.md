# 核心机制知识库

本目录是项目的 **wiki**：沉淀**项目自身核心机制**的权威文档，长期维护、可稳定引用。写什么、不写什么、如何组织见 [`AGENTS.md`](AGENTS.md)。

- 机制**怎么运作** → 本目录
- 外部文献与算法探索 → [`../research/`](../research/)
- 开发过程与实验数据（时点性） → [`../devlog/`](../devlog/)
- 术语与指代约定 → [`../TERMS.md`](../TERMS.md)

## 主题索引

> `README.md` 为唯一索引：新增主题页时在此登记一行（一句话摘要 + 链接）。分类目录与板块一一对应（词表见 [`AGENTS.md`](AGENTS.md) 组织约定）。
>
> 初始化时定义本项目的分类词表；`experiment_result/`（冻结实验结论，收录契约见其 [`README.md`](experiment_result/README.md)）为固定保留项。
